# Data Dictionary – evaluation_100.csv

| Column          | Description                                      |
|-----------------|--------------------------------------------------|
| id              | Unique prompt index (0–99)                       |
| prompt          | Full instruction prompt                          |
| sft_response    | Response generated by SFT model                  |
| ppo_response    | Response generated by PPO model                  |
| reward_sft      | Scalar reward from trained RM                    |
| reward_ppo      | Scalar reward from trained RM                    |
| reward_diff     | reward_ppo − reward_sft                          |
| len_sft         | Word count of SFT response                       |
| len_ppo         | Word count of PPO response                       |
